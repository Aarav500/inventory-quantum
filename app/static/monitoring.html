🔍 Drift Detection & Monitoring

Distributional shift detection without ground truth labels

📊 PSI (Population Stability Index)

PSI = Σ (Ai - Ei) × ln(Ai/Ei)

What it measures: Compares distribution of new data vs training data across bins.

Thresholds:

  • PSI < 0.1: No drift
  • 0.1 ≤ PSI < 0.25: Moderate drift
  • PSI ≥ 0.25: Significant drift

📈 KS Test (Kolmogorov-Smirnov)

D = max|F1(x) - F2(x)|

What it measures: Maximum difference between cumulative distributions.

Why use it: Non-parametric, works for any distribution shape.

Interpretation: p-value < 0.05 indicates significant difference.

❓ Why Monitor Without Labels?

🕐 Real-time Detection

Ground truth (actual sales) arrives days/weeks after predictions. Monitoring needs to be proactive.

📊 Input Distribution

If input features drift, model performance likely degrades even before we see outcomes.

🎯 Early Warning

Detect problems early to retrain before business impact occurs.
